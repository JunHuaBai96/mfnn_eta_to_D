# Pre-submission checklist

1. Compile `main.tex` cleanly (`latexmk -pdf`); resolve undefined references.
2. Confirm frozen Protocol W numbers match the README table (do not edit).
3. Confirm Abstract / Conclusions do **not** cite SI-only oracle diagnostics (post-hoc intercept shift ~9.81%, *k*=2 anchor ~31%).
4. Confirm method wording remains physics-guided residual MFNN (not PINN/PPINN); no Kozlov silent η fill claimed as HF pairing.
5. Cover letter: affiliation and `ycui@njtech.edu.cn` present; send from corresponding author.
6. Acknowledgments vs CRediT: if no specific grant is listed, do not claim Funding acquisition.
7. Package zip: `main.tex`, `refs.bib`, `figures/Fig*.pdf` (and SI), Highlights/Keywords as required by Elsevier — exclude `_archive_private/`, `.venv/`, and broken Word drafts.
8. Optional: regenerate Word from LaTeX if a DOCX track is needed; treat LaTeX as authoritative.
9. Fill real grant number in Acknowledgments **only** if one exists; otherwise leave the no-grant sentence.
10. Illustrator polish of Fig. 1 schema vectors is optional and does not change numeric claims.
